6. 유지 버프 트래킹 바로 띄워서 보기

Void Metamorphosis
영혼 파편 50개(Soul Glutton으로 35개)로 들어간다. Consume·Reap 강화, Void Ray가 Fury를 쓰지 않는다. 그동안 Fury가 서서히 줄고, 다 떨어지면 끝난다 (Wowhead)
Rolling Torment
Void Metamorphosis가 끝날 때 남은 영혼마다 Fury 5와 12초 동안 피해 0.5% 증가
Feast of Souls
영혼 파편마다 6초 동안 피해 1% 증가, 겹쳐 쌓인다
Voidfall
Consume이 35% 확률로 Voidfall 1중첩. 3중첩이면 Reap가 대상 위치에 운석(8미터 광역)

영혼 파편을 모아 Void Metamorphosis에 들어가는 것이 딜의 중심입니다. Void Ray와 Void Metamorphosis는 쓸 수 있게 되면 바로 쓰고, Reap는 영혼이 4개 이상일 때 씁니다 (Wowhead).

Annihilator는 Void Metamorphosis 한 번을 길게 끌며 Collapsing Star를 많이 씁니다. Voidfall 중첩(최대 3)과 남은 Fury를 함께 봅니다.

  1. ESC → Options → Gameplay Enhancements → Advanced Cooldown Settings → Buffs 탭에서 Void Metamorphosis, Rolling Torment, Voidfall를 Tracked Bars 칸으로 옮기기. Tracked Buffs 칸에 두면 막대에 시간이 안 나옵니다.
  2. 영혼 파편 개수는 기본 자원 막대에 나옵니다. Void Metamorphosis 직전에는 Voidblade 쿨을 확인합니다.

게임에서 특성 창(N) → 위쪽 빌드 목록 드롭다운 → Import → 붙여넣기. ★ = Wowhead 추천.
