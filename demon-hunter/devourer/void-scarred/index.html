Void-Scarred

Void-Scarred 빌드 기준으로, 누르는 기술을 사용 시점별로 모았습니다. 기술 카드를 누르면 게임 툴팁이 나옵니다.

1. 기본 딜 순환

Consume
25미터, 2초 시전, 이동 중 시전 가능. Fury 8. 기본 채우기 기술

8초. 대상에게 Cosmic 피해, 주변 영혼 파편 4개를 모은다. 영혼이 4개 이상일 때 쓴다 (Wowhead)
Void Ray
Fury 100, 3초 채널. Fury가 차면 바로 쓴다. 끝까지 채널하면 다음 Reap가 Eradicate가 된다
Eradicate
Void Ray를 끝까지 채널하면 Reap가 Eradicate로 바뀐다. 25미터 전방 원뿔 광역, 영혼 4개
Voidblade
30초. 15미터 돌진 Cosmic 피해. Void Metamorphosis 직전에 쓴다
Hungering Slash
The Hunt·Voidblade 뒤 6초 동안 Voidblade 대신 쓴다. 주변 광역, Fury 10, 영혼 파편 2개 (Void-Scarred 빌드)
Second Helping
Reap 충전 +1 (Void-Scarred 빌드)
Moment of Craving
Void Ray를 끝까지 채널하면 Reap 쿨 초기화, 다음 Reap가 영혼 6개를 더 모은다
Soulshaper
Reap가 모은 영혼 파편 하나마다 Reap 피해 8% 증가

Improved Consume

Eradicate
Void Ray를 끝까지 채널하면 Reap가 Eradicate로 바뀐다. 25미터 전방 원뿔 광역, 영혼 4개

Cull
Void Metamorphosis 중 강화된 Reap. 영혼이 4개 이상이거나 충전이 가득이면 쓴다 (Wowhead)
Collapsing Star

6. 유지 버프 트래킹 바로 띄워서 보기

Void Metamorphosis
영혼 파편 50개(Soul Glutton으로 35개)로 들어간다. Consume·Reap 강화, Void Ray가 Fury를 쓰지 않는다. 그동안 Fury가 서서히 줄고, 다 떨어지면 끝난다 (Wowhead)
Rolling Torment
Void Metamorphosis가 끝날 때 남은 영혼마다 Fury 5와 12초 동안 피해 0.5% 증가
Feast of Souls
영혼 파편마다 6초 동안 피해 1% 증가, 겹쳐 쌓인다

영혼 파편을 모아 Void Metamorphosis에 들어가는 것이 딜의 중심입니다. Void Ray와 Void Metamorphosis는 쓸 수 있게 되면 바로 쓰고, Reap는 영혼이 4개 이상일 때 씁니다 (Wowhead).

Void-Scarred는 Void Metamorphosis에 들어가며 Voidblade·The Hunt를 초기화하고, 근접 기술을 모두 쓴 뒤 빠르게 나옵니다. 끝날 때 Rolling Torment가 남은 영혼만큼 피해를 올립니다.

  1. ESC → Options → Gameplay Enhancements → Advanced Cooldown Settings → Buffs 탭에서 Void Metamorphosis, Rolling Torment를 Tracked Bars 칸으로 옮기기. Tracked Buffs 칸에 두면 막대에 시간이 안 나옵니다.
  2. 영혼 파편 개수는 기본 자원 막대에 나옵니다. Void Metamorphosis 직전에는 Voidblade·The Hunt 쿨을 확인합니다.

특성 빌드 코드 Wowhead 기준 (2026-09-18 갱신, 12.1)

게임에서 특성 창(N) → 위쪽 빌드 목록 드롭다운 → Import → 붙여넣기. ★ = Wowhead 추천.
